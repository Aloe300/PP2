# Practice 09

This folder contains solutions for Lab 9 with `pygame`.

Projects:
- `mickeys_clock` - Mickey style clock with minute and second hands
- `music_player` - music player controlled from keyboard
- `moving_ball` - red ball that moves with arrow keys

How to run:

```bash
pip install -r requirements.txt
python3 mickeys_clock/main.py
python3 music_player/main.py
python3 moving_ball/main.py
```

Notes:
- Put your own `.mp3`, `.wav` or `.ogg` files into `music_player/music/`
- The clock uses system time
- The ball cannot leave the screen
