# Practice 8

PhoneBook project with PostgreSQL stored procedures and functions.

Files:
- `phonebook2.py` - main menu program
- `connect.py` - database connection
- `config.py` - reads database settings from `database.ini`
- `functions.sql` - SQL functions
- `procedures.sql` - SQL procedures
- `database.ini` - PostgreSQL connection settings

Run:

```bash
python3 phonebook2.py
```

Before running, check `database.ini` and make sure the database settings match your local PostgreSQL setup.
